# Real-Time Object Detection using YOLOv9c

Implementation of the paper:
> *Real-Time Object Detection using Yolov9c and Flask Web Application*  
> Bhukya Chinni Krishna — DELCON 2024, IEEE

## Overview
This notebook implements YOLOv9c-based object detection across three modalities:
- Image detection — 94.7% accuracy
- Video detection — 93.5% accuracy  
- Webcam detection — 92.8% accuracy

## Dataset
COCO128 — 128 images across 80 object classes (subset of COCO 2017)

## Requirements
- Python 3.10+
- ultralytics
- OpenCV
- PyTorch (CUDA recommended)
